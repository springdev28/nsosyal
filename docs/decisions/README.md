# Karar kayıtları

Prototipin gidişatını değiştiren kararlar burada tutulur. Amaç, aylar sonra "bu
neden böyle?" sorusuna kodu tersine mühendislik yapmadan cevap verebilmek — ve
yarışma jürisine kararın gerekçesini gösterebilmek.

Her kayıt aynı iskeleti kullanır: **Durum · Bağlam · Karar · Sonuçlar ·
Değerlendirilen alternatifler.**

Bir karar değiştiğinde kaydı silmeyin: durumunu `Değiştirildi` yapıp yeni kaydı
işaret edin.
